Siap main?

Gerakkan paddle, lalu luncurkan bola dengan klik atau Spasi.

🎮 Kontrol

  • 🖱️ MouseGerakkan ke kiri / kanan, klik untuk meluncurkan bola
  • 📱 Layar sentuhGeser jari untuk menggerakkan paddle, ketuk untuk meluncurkan bola
  • ←→ KeyboardAtau tombol A D
  • Spasi Luncurkan / jedaBisa juga dengan tombol P
  • R M Mulai ulang / suaraR mengulang dari awal, M menyalakan atau mematikan suara

📖 Cara bermain

  1. Luncurkan bola, lalu pantulkan dengan paddle di bawah.
  2. Hancurkan semua balok untuk lanjut ke level berikutnya.
  3. Kena ujung paddle = bola memantul miring, kena tengah = lurus ke atas.
  4. Kalau bola jatuh, nyawa berkurang. Habis 3 nyawa, game over.
  5. Tiap level bola makin cepat dan susunan balok berubah.

🏅 Poin

  • Balok baris atas bernilai paling besar (60), baris bawah paling kecil (10).
  • Balok bergaris tebal butuh 2 pukulan dan bernilai ganda.
  • Selesaikan level dengan nyawa utuh untuk bonus +50 per nyawa.
  • Rekor disimpan per tingkat kesulitan di browsermu.
